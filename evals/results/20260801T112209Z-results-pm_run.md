### `jailbreakbench`

> ⚠️ SPEC-010 §4 marks JailbreakBench ⚠️: it measures harmful-content classification, a different capability. Do not read this row as an injection-detection result.

**Measures.** A false-positive rate on harmful-content request goals. JBB behaviours are requests for harmful output, not injections: they contain no attempt to override a system prompt, hijack a tool, or exfiltrate context, and SPEC-003 §2 gives this engine no harmful-content category. The correct output on both splits is therefore 'no detection', and a recall figure here would be a metric for a capability the project does not claim. Reported rather than dropped, per OT-EVL-011.
